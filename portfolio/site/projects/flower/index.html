Ouest INSA / Information systems

Flower

Software for managing client studies

Ouest INSA’s information systems team develops Flower, the association’s ERP/CRM. I contributed to its development and maintenance, working on study amendments, document generation and the interfaces the team uses to manage studies.

Explore the public code ↗

The problem

Ouest INSA manages studies for clients. A study has requirements, phases of work and an agreement. If the budget or deadline changes, the team needs to record the amendment and keep track of which terms apply.

Approach

Team members edit studies in a Vue 3 interface written in JavaScript. A Python backend uses Django and Django REST Framework to read and update records in MySQL or MariaDB. The document generator draws on those same records when it prepares an agreement.

My contributions

  • Study amendments

    I reworked the amendment creation form and added an editing view that uses the same form. A team member can record changes such as a revised deadline or budget.

Results and limits

The public code shows how a team member can record a change, connect work to its requirements and download an editable agreement. I have no usage figures or measurements of time saved to report.
